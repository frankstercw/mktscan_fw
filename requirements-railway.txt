# MktScan — Railway deployment requirements.
#
# Identical to requirements.txt except that torch and transformers are omitted.
#
# Why: torch is ~2.5GB installed. On Railway that means a very slow build, an
# image near or over the size limit, and a container that needs ~2GB RAM just to
# hold FinBERT's weights. build_scorer() falls back to VADER automatically when
# transformers is unavailable, so the app runs correctly without them — it just
# scores sentiment with VADER instead of FinBERT.
#
# Sentiment is only 12% of the composite weight, so this is a smaller quality
# hit than it sounds. If you want FinBERT-grade sentiment on Railway, set
# MKTSCAN_SENTIMENT_MODEL=openai and MKTSCAN_OPENAI_KEY instead — comparable
# quality, no 2.5GB dependency, roughly $0.001 per article batch.
